# BiBi / TIA DCA: исходники первого спринта

Демо: https://kiton.pw/bibi/

Расчёт нового взноса по бумагам и целевым долям пользователя. Реальные сделки не исполняются. Данные примера условные

## Запуск
Node.js 20+: `npm start`, открыть http://127.0.0.1:4173. Без установки: открыть dist/BiBi.html. Основной веб-сценарий не требует npm-зависимостей или API-ключей

## Проверки
`npm test`
`npm ci --prefix mcp --ignore-scripts` и `npm --prefix mcp test`
`npm ci --prefix quality --ignore-scripts`, из quality: `npx playwright install`, затем из корня `node quality/browser.mjs`
`node quality/workspace.mjs` проверяет совместное локальное хранилище и MCP на синтетических данных

## Проверка за 90 секунд
Пример 70/30, цель 50/50, взнос 20 000 ₽: покупки B 19 000 ₽, комиссия 9,50 ₽, остаток 990,50 ₽. Сохранить расчёт, открыть историю, условно учесть покупки в примере и рассчитать следующий взнос. После второго взноса покупки 20 000 ₽, комиссия 10 ₽, остаток 980,50 ₽

## MCP
Описание инструментов в mcp/README.md. Для общего локального интерфейса `npm run workspace`, порт 4188. MCP запускается `node mcp/server.mjs`. Не публиковать локальный API портфелей в интернет. Публичный сайт и локальный workspace используют разные хранилища

## Границы
Ядро не выбирает стратегию, не прогнозирует доходность, не подключает брокерский счёт. Котировки MOEX могут быть задержаны. Банковская интеграция, производственная нагрузка и реальные телефоны не подтверждены. Детерминированные тесты не являются пользовательскими интервью
