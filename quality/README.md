# Воспроизводимые браузерные проверки

Общая локальная копия и MCP: `node quality/workspace.mjs`. В каждом из трёх движков создаются временное хранилище и синтетический MCP-процесс. Проверяются обмен в обе стороны, котировки-фикстуры, отдельная модель, история, поздний polling, конфликт браузера/ИИ и перезагрузка. Результат: `qa/workspace/checks.json`. Рабочие портфели не используются

Из корня проекта:

```shell
npm ci --prefix quality --ignore-scripts
npm run build
npm --prefix quality test
```

Нужны браузеры, соответствующие Playwright 1.60.0. Если их нет, установить их из каталога `quality` командой `npx playwright install chromium firefox webkit`. Версия закреплена для повторения проверенной матрицы; перед обновлением повторить аудит и прогон.

После установки отсутствовавшего движка можно проверить только его: `BIBI_TEST_ENGINES=firefox` (в PowerShell: `$env:BIBI_TEST_ENGINES='firefox'`). Допускается список через запятую. Без переменной проверяются все три. Сохраняйте отчёты предыдущих прогонов, если объединяете их доказательства. При завершении скрипт закрывает все соединения только своего временного сервера, включая неиспользованные браузерные соединения.

Скрипт сам поднимает HTTP на свободном loopback-порту, запускает отдельные чистые контексты и завершает их. Root-сервер сайта не требует npm-зависимостей; browser tooling и MCP устанавливаются отдельно.

Проверяются Chromium, Firefox и WebKit; размеры 320×740, 390×844, 768×1024, 1440×1000; две темы; пример с двумя взносами; ручной портфель; ошибки бюджета и записи покупок; история; копии; CSV; XSS; поздний ответ отзыва; клавиатура; сетевые отказы и сброс. Отдельно открывается переносимый HTML с блокировкой HTTP/S-запросов. Это воспроизводит отсутствие доступа к веб-ресурсам, а не отключение сетевого адаптера ОС.

Скриншоты и JSON-результаты находятся в игнорируемой папке `qa/agent-ready`. При недоступном движке проверка явно попадает в `skipped`; это не успешный тест. Физические iPhone/Android, реальная экранная клавиатура, VoiceOver/TalkBack и нагрузка большого числа пользователей этой матрицей не подтверждаются. Увеличение текста до 20 px не выдаётся за полноценную проверку системного zoom.

Финансовые данные только синтетические. UI-отзывы перехватываются; скрипт проверяет, что серверные счётчики не пополнились. Эти данные нельзя считать интервью, конверсией или реальным регулярным использованием.

Для ручной проверки с телефона сначала согласовать тестовый адрес или безопасный доступ по локальной сети. В текущем сервере Host ограничен: нестандартный адрес требует явного `BIBI_PUBLIC_ORIGIN`. Не открывать в интернет произвольный порт только ради проверки; использовать синтетический план.
